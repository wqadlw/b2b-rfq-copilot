# REPO POLICY · 仓库内容政策

> 密级：公开 · 版本 v1.0 · 2026-09-12

## 1. 仓库定位

b2b-rfq-copilot 是开源的通用垂直行业 B2B 智能询盘引擎。本仓库包含：引擎代码（`core/ ports/ adapters/`）、公开工程文档（`docs/`）、评测资产（`eval/`）。**内部工程治理知识库与特定站点的集成实现不在本仓库**。

## 2. 禁入清单（贡献者与维护者共同遵守）

以下内容**永不进入**本仓库（代码/测试/文档/截图/评测数据/commit message）：

1. 真实 API Token、数据库连接串、任何可用凭据字面量——密钥只走环境变量（仅提交 `.env.example`）。
2. 真实生产域名、内部接口生产路径、内网拓扑。
3. 真实客户/供应商数据、真实联系方式、真实询盘内容。
4. 特定站点私有表结构全量映射与内部业务实现。
5. 未经脱敏的 bad case 与日志。

演示与测试一律使用 `adapters/demo/` 的 `demo-` 前缀模拟数据。

## 3. 依赖与提交

- 依赖锁定（lockfile）提交；新增依赖在 PR 中说明理由。
- Conventional Commits；一任务一分支；CI（lint + test + manifest 校验 + 密钥扫描）全绿方可合并。
- 禁止 force push 主分支。

## 4. AI 辅助开发披露

本项目在人类工程主导下采用 AI 辅助开发（架构设计、代码实现、评测构造均经人工评审与测试门禁）。我们认为透明披露是负责任的做法；评测报告与红队用例公开可查。

## 5. 安全报告

发现安全漏洞请使用 GitHub **Private Vulnerability Reporting**，勿公开 issue。影响范围涵盖：提示词注入绕过、检索投毒、越权写操作、PII 泄露。
