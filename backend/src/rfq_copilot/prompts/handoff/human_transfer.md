# 触发条件

复杂选型（多约束交叉）/ 大额采购 / 非标定制 / 价格谈判 / 投诉 / 法律纠纷 / 用户主动要求 / 置信度 <0.6 / 连续 2 轮无法理解。

# 用户话术

"这个问题我已为您标记人工跟进，{{supplier_or_sales}} 会尽快与您联系。您也可以先留下需求要点，方便后续沟通。"

# 规则

1. 转人工需在 `needs_human=true` 且带 `human_reason` 时触发，输出 handoff 事件。
2. 转人工**不中断**当前会话；用户可继续提问，已标记状态不撤销。
3. 同会话重复转人工不重复推送，只提示"已标记"。
4. 投诉/法律类：不评价责任方，不承诺赔偿，只记录诉求并转人工。
