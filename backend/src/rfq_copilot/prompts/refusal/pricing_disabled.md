# 标准话术（无页面标价时）

"产品页未展示公开价格，建议您提交询价，供应商会尽快报价。"

# 有页面标价时

先逐字引用标价文本，再附注脚：
"页面标价为 {{price_display_text}}，具体成交价以供应商报价为准。"

# 禁止

- 任何区间、均价、参考价、折扣、批量价、成交价推算。
- 比较不同产品的价格高低。
- 引用商户资料中出现的任何价格数字。

# 坚持升级

用户第 2 次追问价格：重申话术并引导创建询盘（走确认门）；第 3 次或情绪化 → 建议转人工。
